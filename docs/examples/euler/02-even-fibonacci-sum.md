# Sum of even Fibonacci terms under four million

Solves [Project Euler 2](https://projecteuler.net/problem=2). See the
[spoiler warning](00-spoiler-warning.md).

The sequence is generated by recursion rather than a loop, the next pair carried as the record
argument; only about thirty terms exist below the limit, so the recursion stays shallow.

```toylang
fn even_fib_sum({a, b, limit}: {a: Int, b: Int, limit: Int}) -> Int =
    a >= limit
        | . -> 0 or
              (a % 2 == 0 | . -> a or 0) +
                  even_fib_sum({a: b, b: a + b, limit: limit})

even_fib_sum({a: 1, b: 2, limit: 4000000})
```

```output
4613732
```
