# Sum of even Fibonacci terms under four million

Solves [Project Euler 2](https://projecteuler.net/problem=2). See the
[spoiler warning](00-spoiler-warning.md).

The sequence is generated by recursion rather than a loop, a fold in the base case and the
next pair carried as a record; only about thirty terms exist below the limit, so the
recursion stays shallow.

```toylang
fn even_fib_sum(p: {a: Int, b: Int, limit: Int}) -> Int =
    0 if p.a >= p.limit else
    (p.a if p.a % 2 == 0 else 0) + even_fib_sum({a: p.b, b: p.a + p.b, limit: p.limit})

even_fib_sum({a: 1, b: 2, limit: 4000000})
```

```output
4613732
```
