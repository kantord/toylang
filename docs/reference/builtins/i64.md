# i64

`i64(n)`, of type `Int -> Int64`: the one bridge between the two integer types. Nothing
widens implicitly ([ADR 0010](../../adr/0010-int64-is-a-second-integer-type.md)), so an `Int`
that has to take part in [Int64](../types/int64.md) arithmetic is widened by name, where a
reader can see it:

```toylang
fn stamp() -> Int64 = 1756500000000

fn plus_seconds(s: Int) -> Int64 = stamp() + i64(s) * 1000

plus_seconds(90)
```

```output
1756500090000
```

The conversion is exact -- every `Int` fits an `Int64` -- and it is the whole surface: there
is no narrowing back, and no other pair of types converts at all.

`i64` takes only `Int`, so its own argument obeys the 32-bit literal rule. `i64(9000000000)`
is refused -- the argument does not fit `Int` -- because a wide value enters as a literal
only where an `Int64` is already expected, never through the bridge:

```toylang
i64(9000000000)
```

```error
integer `9000000000` does not fit in Int, which is 32 bits; only a position that expects Int64 can hold it (at byte 4)
```
